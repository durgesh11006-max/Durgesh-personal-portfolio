# Durgesh Yadav – Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my skills, education, and journey as an aspiring software developer.

## 🚀 Project Overview

This portfolio website is developed using HTML5, CSS3, and JavaScript. It features a modern design with responsive layouts for mobile, tablet, and desktop devices.

## 🎯 Module 02: Responsive Design & Styling

This project demonstrates the practical implementation of responsive web design and modern CSS styling techniques.

### Key Features

- Fully responsive design for mobile, tablet, and desktop.
- CSS Flexbox for flexible layouts.
- CSS Grid for structured content sections.
- Modern color combinations and typography.
- Styled buttons with hover effects.
- Navigation bar with smooth scrolling.
- Interactive mobile hamburger menu.
- Contact form with basic validation.
- Automatic copyright year.
